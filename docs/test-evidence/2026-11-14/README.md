# Video evidence

These videos record a fresh rerun of the OTP success cases on
`sync-dating.localhost`. They are not recordings of the original run.

Each case has its own recording, linked from
`../../test-otp-verification-2026-11-14.md`.

Video files and recorder sidecars are local, Git-ignored artifacts. They are not
included in repository clones. The reports and recording manifest remain tracked.

Recordings show configured test identities and visible OTP fields. Treat them as
internal test evidence; do not publish them or reuse the credentials elsewhere.
